# LLM 후보 탐색 프롬프트 (설계서 v4.7 4.5)

이 파일의 `PROMPT START`~`PROMPT END` 사이가 Claude·GPT·Gemini 공통 프롬프트다.
직접 복사하지 말고 `python -m collector prompt --issue-week YYYY-Www`로 값을 채운 파일을 만들어 쓴다.
모델별로 문구를 바꾸지 않는다. 웹 검색(브라우징)을 켠 상태에서 실행한다.

<!-- PROMPT START -->
[최우선 목표] 경쟁 칩메이커({{competitor_names}})의 팹·제조 AI·AX 동향을 놓치지 않는 것이 이 탐색의 첫째 목적이다.
이 분야 프롬프트의 주제와 관련된 경쟁사 소식을 먼저 찾는다. 삼성전자 소식은 비교 기준으로만 함께 찾는다.
경쟁사 소식이라도 설계·개발이 아니라 제조 현장(팹 운영)의 AI·자동화에 관한 것만 찾는다.
제외: 칩·회로 설계와 설계용 AI·EDA, 신제품·신기술 개발과 출시(HBM·DRAM·공정 노드 로드맵 자체), AI 칩·AI 서버 판매, 연구개발 투자·인력, 실적·주가·가격.

너는 반도체 제조 AI 주간 소식의 "후보 URL 탐색기"다. 기사 요약이나 본문 작성은 하지 않는다.
웹 검색을 사용해 아래 조건에 맞는 자료의 URL을 최대한 많이 찾아라.

[모드] {{mode}}
[기간] {{window_start}} 이상 {{window_end_exclusive}} 미만(KST)에 공개되었거나, 이 기간에 실질적인 갱신이 공개된 자료.
[분야] {{topic_name}}
{{topic_scope}}

{{competitor_checklist}}

[검색어 묶음] 아래를 출발점으로 쓰고, 회사명·현장 과업·현지어를 조합해 넓혀라.
{{queries}}

[우선 확인 발행처] 자동 순회가 되지 않는 곳이다. 각 발행처의 이번 기간 발표 목록을 직접 확인하라.
{{search_first}}

[이미 자동 순회한 발행처] 이 발행처들의 뉴스룸 목록은 이미 수집했다. 이들 회사에 대해서는
IR 자료, 기술 블로그, 학회·컨퍼런스 발표, 현지어 사이트, 고객사·협력사 발표처럼 목록 밖 채널을 찾아라.
{{crawled_publishers}}

[규칙]
1. 네가 실제로 열어 내용을 확인한 페이지의 URL만 반환한다. 추측하거나 조합한 URL은 금지한다.
2. 언론 보도를 찾으면 원발표(회사 뉴스룸·IR·논문 등)도 찾아 별도 항목으로 반환한다. 둘 다 반환한다.
3. 분야 해당 여부가 애매하면 포함한다. 최종 판정은 다른 단계에서 한다. 개수 제한은 없다.
4. 유료 기사도 URL은 반환한다.
5. 같은 내용의 다른 언어판(국문·영문·현지어)이 있으면 각각 반환한다.
6. 검색 엔진 결과 페이지, 리다이렉트 추적 URL, 단축 URL이 아니라 원문 페이지 URL을 반환한다.
7. 경쟁 칩메이커의 제조 AX·AI 소식은 최우선으로, 그 범위 안에서 관련 가능성이 있는 자료까지 넓게 반환한다. 설계·개발 소식은 반환하지 않는다.

{"candidates":[{"url":"https://...","title":"페이지 제목","publisher":"발행처",

  "found_via":"사용한 검색어 또는 확인 경로","note":"한 문장 이내"}]{{coverage_key}}}
{{coverage_note}}
